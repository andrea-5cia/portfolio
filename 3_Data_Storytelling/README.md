# 🎨 Data Storytelling

> **Note:** This section uses **PDFs or images only** for narrative projects such as analytical reports, infographics, or presentations.

## 🎯 Goal
_Describe the data story, the target audience, and the main question it answers._

## ✍️ Typical Content
- Thematic reports (PDF)
- Infographics (PNG, PDF)
- Slide decks (PDF exported from PowerPoint)

## 📂 Suggested Project Structure
```
📁 Storytelling_Project/
├── presentation.pdf   # final presentation or report
├── infographic.png    # (optional) infographic visual
└── README.md
```

## 📝 Example README for a Data Storytelling Project
```markdown
# Student Orientation Analysis
**Context:** Study on the impact of orientation activities on STEM enrollments.  
**Output:** Executive PDF report and summary infographic.

📘 [View Presentation](presentation.pdf)  
🖼️ ![Infographic](infographic.png)
```
